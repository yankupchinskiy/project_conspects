## Файловая система FAT32
Выделяется 32 бита для хранения адреса кластера, $2^{32}$ Кластеров. По умолчанию один кластер занимает 4 кбайта
суммарный максимальный обьём системы 16тб

## Недостатки
	-Ограниченна максимальна ядлинна имени 
	-Фрагментация 
	-потери вызванные большими кластерами файлов
## Структура тома NTFS
### отрезок-экстент, базовая единица распределения пространства, непрерывная последовательность кластеров
### MFT-Master File Table
Содержит как минимум одну запись для каждого файла тома + 1 для самого себя
### Каждая запись имеет фиксированный размер 1,2 или 4 кб
### 1й отрезок содержит 16 стд записей о системных файлах NTFS создающихся при лог. форматировании
