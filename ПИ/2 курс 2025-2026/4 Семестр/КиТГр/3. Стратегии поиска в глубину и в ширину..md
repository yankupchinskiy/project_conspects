Ниже представлен подробный, структурированный и полный разбор двух фундаментальных стратегий обхода графов: **поиска в глубину** (Depth‑First Search, DFS) и **поиска в ширину** (Breadth‑First Search, BFS). Рассматриваются алгоритмы, их свойства, сложность, псевдокод и основные области применения. Материал изложен в удобном для чтения формате с четкими акцентами.

---

## 3.1. Введение: что такое обход графа

**Обход графа** — это систематическая процедура посещения всех его вершин (и/или рёбер) по определённым правилам, начиная с одной или нескольких стартовых вершин. Обход лежит в основе подавляющего большинства графовых алгоритмов:

- поиск путей и циклов;
- проверка связности;
- топологическая сортировка;
- построение каркасов;
- выделение компонент сильной связности;
- анализ достижимости и т. д.

Две классические стратегии — **поиск в глубину** и **поиск в ширину** — отличаются порядком посещения вершин и, как следствие, сферой применения.

---

## 3.2. Поиск в глубину (DFS)

### 3.2.1. Основная идея
DFS исследует граф, «углубляясь» в него насколько возможно, прежде чем отступать (backtrack). Попав в новую вершину, алгоритм немедленно пытается перейти к её ещё не посещённому соседу; если все соседи уже посещены, происходит возврат к предыдущей вершине и продолжение поиска в другом направлении.

Это напоминает прохождение лабиринта с верёвкой: в каждой развилке идём по одному из проходов до тупика, затем по верёвке возвращаемся к предыдущей развилке и пробуем другой проход.

### 3.2.2. Алгоритм

DFS может быть реализован **рекурсивно** (наиболее естественно) или **итеративно** с явным использованием стека.

#### Рекурсивная версия (для неориентированного графа)
```
Функция DFS(граф G, вершина v, массив visited):
    visited[v] ← true
    обработать v (например, вывести)
    для каждого соседа u вершины v:
        если visited[u] = false:
            DFS(G, u, visited)
```
Для обхода всего графа (возможно, несвязного) используется внешний цикл:
```
для каждой вершины v ∈ V:
    если visited[v] = false:
        DFS(G, v, visited)
```

**Псевдокод для ориентированного графа** аналогичен, только соседи — это вершины, в которые ведут дуги из текущей.

#### Итеративная версия (с явным стеком)
```
DFS_iter(G, start):
    стек S
    S.push(start)
    visited[start] ← true
    пока S не пуст:
        v ← S.pop()
        обработать(v)
        для каждого соседа u вершины v:
            если visited[u] = false:
                visited[u] ← true
                S.push(u)
```
> **Замечание:** Порядок обхода в итеративной версии может отличаться от рекурсивной (обратный порядок соседей), но общая глубокая стратегия сохраняется.

### 3.2.3. Временная и пространственная сложность

При представлении графа **списками смежности**:
- **Время:** $O(V + E)$ — каждая вершина обрабатывается один раз, каждое ребро просматривается дважды (для неориентированного) или один раз (для ориентированного).
- **Память:** $O(V)$ в худшем случае для стека вызовов (рекурсивный DFS) или явного стека при глубокой рекурсии (например, граф-цепочка). Плюс массив `visited` размером $O(V)$.

Для **матрицы смежности** время возрастает до $O(V^2)$ из-за необходимости перебора всех потенциальных соседей.

### 3.2.4. Времена входа и выхода (таймстемпы)

При обходе DFS часто сохраняют два временных штампа для каждой вершины:
- **`d[v]` (discovery time)** — момент, когда вершина впервые посещена;
- **`f[v]` (finish time)** — момент, когда все её потомки полностью обработаны и алгоритм покидает вершину.

Эти метки позволяют классифицировать рёбра и лежат в основе алгоритмов топологической сортировки и поиска компонент сильной связности.

### 3.2.5. Классификация рёбер (ориентированный граф)

В процессе DFS все дуги ориентированного графа делятся на четыре типа:
1. **Древесные рёбра (tree edges)** — ведут к ещё не посещённой вершине (составляют лес DFS).
2. **Обратные рёбра (back edges)** — соединяют вершину с её предком в DFS‑дереве (указывают на наличие цикла).
3. **Прямые рёбра (forward edges)** — соединяют вершину с её потомком, но не являются древесными.
4. **Перекрёстные рёбра (cross edges)** — все остальные (между вершинами из разных ветвей дерева).

В **неориентированном** графе после DFS каждое ребро будет либо древесным, либо обратным. Прямых и перекрёстных рёбер не возникает.

### 3.2.6. Свойства и ключевые применения

1. **Обнаружение циклов.**  
   Если в ориентированном графе при обходе встречается обратное ребро, то граф содержит цикл. Для неориентированного графа — если ребро ведёт к уже посещённой вершине, не являющейся непосредственным родителем.

2. **Топологическая сортировка ориентированного ациклического графа (DAG).**  
   После завершения обхода DFS можно вывести вершины в порядке убывания времени выхода $f[v]$. Это даст линейное упорядочение вершин, при котором все дуги направлены из более ранней вершины в более позднюю.

3. **Выделение компонент сильной связности (алгоритм Косарайю, Тарьяна).**  
   DFS используется для нахождения сильно связных компонент в орграфе.

4. **Проверка связности и выделение компонент связности.**  
   Одиночный запуск DFS определяет все вершины, достижимые из стартовой. Последовательные запуски из непосещённых вершин выявляют все компоненты связности.

5. **Построение каркаса (остова) графа.**  
   Древесные рёбра DFS образуют DFS‑дерево (или лес), которое является каркасом исходного графа.

6. **Поиск точек сочленения и мостов (алгоритм на основе DFS).**

7. **Решение лабиринтов, генерация лабиринтов.**

### 3.2.7. Пример обхода

Рассмотрим неориентированный граф:
```
    1
   / \
  2   3
 / \
4   5
```
Обход DFS, начиная с вершины 1, при порядке соседей (2, 3):
- Посетили 1 → идём в 2 → идём в 4 → возврат к 2 → идём в 5 → возврат к 2 → возврат к 1 → идём в 3.
Порядок посещения: 1, 2, 4, 5, 3.

## 3.3. Поиск в ширину (BFS)

### 3.3.1. Основная идея
BFS исследует граф «послойно»: сначала посещает все вершины на расстоянии 1 от стартовой, затем на расстоянии 2 и так далее. Для реализации используется **очередь** (FIFO). Это напоминает распространение волны от источника.

### 3.3.2. Алгоритм

```
BFS(граф G, стартовая вершина s):
    создать очередь Q
    visited[s] ← true
    расстояние dist[s] ← 0
    Q.enqueue(s)
    пока Q не пуста:
        v ← Q.dequeue()
        обработать(v)
        для каждого соседа u вершины v:
            если visited[u] = false:
                visited[u] ← true
                dist[u] ← dist[v] + 1
                родитель parent[u] ← v   // для восстановления пути
                Q.enqueue(u)
```

Для обхода всего графа добавляется внешний цикл по всем вершинам, аналогично DFS.

### 3.3.3. Временная и пространственная сложность

При представлении списками смежности:
- **Время:** $O(V + E)$ — каждая вершина попадает в очередь один раз, каждое ребро просматривается (для неориентированного — дважды).
- **Память:** $O(V)$ — размер очереди в худшем случае (например, на последнем уровне может находиться до $O(V)$ вершин), плюс массивы `visited`, `dist`, `parent`.

При матрице смежности время возрастает до $O(V^2)$.

### 3.3.4. Свойства и ключевые применения

1. **Кратчайшие пути в невзвешенном графе.**  
   BFS находит длины кратчайших путей (в рёбрах) от стартовой вершины до всех достижимых. Массив `dist` хранит эти расстояния. Восстановление пути — по массиву `parent`.

2. **Проверка двудольности графа.**  
   Раскрашивая вершины в два цвета (по чётности расстояния), BFS может определить, является ли граф двудольным: если ребро соединяет вершины одного цвета — граф не двудолен.

3. **Волновой алгоритм (алгоритм Ли)** используется в трассировке печатных плат и поиске пути на сетке.

4. **Поиск компонент связности** — аналогично DFS, но порядок вершин иной.

5. **Поиск в ширину на графах с весами 0 и 1** (алгоритм 0‑1 BFS, использующий дек).

6. **Обход «по уровням»** в задачах, где важно обрабатывать вершины в порядке близости к источнику (социальные сети, веб‑краулеры с ограничением глубины).

7. **Построение BFS‑дерева (каркаса).**

### 3.3.5. Пример обхода

На том же графе, начиная с вершины 1:
- Очередь: [1] → достаём 1, добавляем 2 и 3 → очередь [2,3].
- Достаём 2, добавляем 4 и 5 → очередь [3,4,5].
- Достаём 3 (соседи 1 уже посещён) → [4,5].
- Достаём 4 → [5].
- Достаём 5 → [].
Порядок посещения: 1, 2, 3, 4, 5.

## 3.4. Сравнение DFS и BFS

| Характеристика               | Поиск в глубину (DFS)                           | Поиск в ширину (BFS)                             |
|------------------------------|--------------------------------------------------|--------------------------------------------------|
| **Структура данных**         | Стек (рекурсия или явный)                        | Очередь (FIFO)                                   |
| **Порядок обхода**           | Вглубь до тупика, затем возврат                  | Послойно, по уровням                             |
| **Временная сложность**      | $O(V + E)$ (списки смежности)                 | $O(V + E)$ (списки смежности)                 |
| **Память (доп. к visited)**  | $O(V)$ для стека (глубина рекурсии)           | $O(V)$ для очереди (ширина текущего уровня)    |
| **Полнота**                  | Обходит все вершины, достижимые из источника     | Обходит все вершины, достижимые из источника     |
| **Кратчайшие пути**          | Не гарантирует (находит произвольный путь)       | Находит кратчайшие пути в невзвешенном графе     |
| **Обнаружение циклов**       | Да, по обратным рёбрам                           | Да, при модификации, но менее естественно        |
| **Топологическая сортировка**| Да (для DAG)                                     | Нет (требуются другие подходы)                   |
| **Двудольность**             | Возможно, но BFS удобнее                          | Да, раскраска по уровням                         |
| **Рекурсивная реализация**   | Очень естественна                                | Не используется (только итеративная)              |
| **Типичное применение**      | Компоненты связности, топсорт, SCC, мосты, циклы | Кратчайший путь, уровни, двудольность, волна     |

## 3.5. Сводка основных применений

| Задача                                         | Предпочтительный алгоритм | Примечание                                                     |
|------------------------------------------------|---------------------------|----------------------------------------------------------------|
| Поиск в лабиринте (единственный путь)          | DFS                       | Может быстрее найти глубоко спрятанную цель (но не кратчайший)  |
| Поиск кратчайшего пути в невзвешенном графе    | BFS                       | Основное свойство BFS                                           |
| Проверка графа на двудольность                 | BFS                       | Очень естественно: раскраска по слоям                           |
| Топологическая сортировка DAG                  | DFS                       | По времени выхода                                               |
| Поиск компонент сильной связности              | DFS                       | Алгоритмы Косарайю, Тарьяна                                     |
| Поиск циклов                                   | DFS                       | Обнаружение обратных рёбер                                      |
| Поиск мостов и точек сочленения                | DFS                       | На основе времен входа и `low`-значений                         |
| Поиск всех вершин на расстоянии ≤ k             | BFS                       | Остановка при достижении глубины k                              |
| Генерация лабиринтов                           | DFS (Randomized)          | Случайный DFS даёт длинные коридоры                             |
| Web crawling (ограниченная глубина)            | BFS                       | Обеспечивает обход ближайших страниц в первую очередь           |

## 3.6. Заключение

Поиск в глубину и поиск в ширину — два краеугольных алгоритма на графах, лежащие в основе многих более сложных методов. **DFS** эксплуатирует стек (рекурсию) и естественно подходит для задач, требующих исследования структуры графа «вглубь», включая топологическую сортировку, выделение сильно связных компонент и поиск циклов. **BFS** использует очередь и идеально решает задачи, связанные с близостью и расстоянием, — прежде всего нахождение кратчайших путей в невзвешенных графах, проверку двудольности и послойный анализ.

Выбор между ними определяется конкретной постановкой задачи: нужен ли кратчайший путь, важна ли послойная обработка, требуется ли естественная рекурсивная декомпозиция (DFS) или итеративное распространение по уровням (BFS). Знание свойств и временных характеристик обоих алгоритмов является обязательным минимумом для любого специалиста по алгоритмам и структурам данных.
