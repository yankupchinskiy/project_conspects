## 22. Алгоритмы Прима и Краскала

Построение **минимального остовного дерева** (Minimum Spanning Tree, MST) — одна из фундаментальных задач теории графов и комбинаторной оптимизации. Имеется взвешенный неориентированный связный граф $G = (V, E)$ с весовой функцией $w: E \to \mathbb{R}$. Требуется найти остовное дерево $T \subseteq E$, сумма весов рёбер которого минимальна:

$$
\min_{T \text{ — остов}} \sum_{e \in T} w(e).
$$

Алгоритмы Прима (Prim, 1957) и Краскала (Kruskal, 1956) — два классических жадных алгоритма, решающих эту задачу за полиномиальное время. Они оба основаны на общем свойстве безопасных рёбер, но различаются способом выбора.

---

### 22.1. Основные понятия и свойства MST

- **Остовное дерево** — подграф, содержащий все вершины и являющийся деревом (связный, без циклов).
- **Разрез** (cut) — разбиение вершин $(S, V \setminus S)$. Ребро пересекает разрез, если один его конец в $S$, другой — в $V \setminus S$.
- **Безопасное ребро** для некоторого подмножества рёбер $A$, которое является подмножеством некоторого MST: ребро, которое можно добавить к $A$, не нарушая свойства «$A$ подмножество MST».

**Теорема о безопасном ребре (generic MST algorithm).**  
Пусть $A \subseteq E$ — подмножество некоторого MST. Пусть $(S, V \setminus S)$ — разрез, который не пересекается ни одним ребром из $A$ (т.е. все рёбра $A$ либо полностью внутри $S$, либо полностью вне $S$). Тогда ребро минимального веса, пересекающее этот разрез, является безопасным для $A$.

Алгоритм Прима использует это свойство, расширяя компоненту связности $A$ (всегда одно дерево), а алгоритм Краскала — поддерживая лес, где каждое добавляемое ребро является минимальным среди оставшихся и не создаёт цикла.

---

### 22.2. Алгоритм Прима

#### Идея
Алгоритм Прима строит MST, начиная с произвольной вершины и постепенно подключая ближайшую вершину к уже построенному дереву. На каждом шаге выбирается ребро минимального веса, соединяющее вершину из дерева с вершиной вне дерева. Это эквивалентно разрезу $(S, V \setminus S)$, где $S$ — множество вершин уже построенного дерева.

#### Псевдокод

```
Prim(G, w, root):
    инициализировать:
        для каждой вершины v:
            key[v] = ∞        // минимальный вес ребра, соединяющего v с деревом
            parent[v] = null  // предок в MST
            inMST[v] = false  // флаг принадлежности дереву

    key[root] = 0
    priority queue Q содержит все вершины v с приоритетом key[v]

    пока Q не пуста:
        u = Q.extract_min()   // извлечение вершины с минимальным ключом
        inMST[u] = true

        для каждого соседа v вершины u:
            если v ∈ Q и w(u,v) < key[v]:
                parent[v] = u
                key[v] = w(u,v)
                Q.decrease_key(v, key[v])

    вернуть множество рёбер {(parent[v], v) | v ≠ root}
```

**Пояснения:**  
- `key[v]` — вес наименьшего ребра, соединяющего $v$ с текущим деревом $S$.  
- При добавлении вершины $u$ в $S$ обновляются ключи её соседей.

#### Временная сложность
- С простой очередью с приоритетами (двоичная куча): $O(|E| \log |V|)$. Каждое ребро обрабатывается один раз при обновлении ключа (decrease_key) за $O(\log |V|)$.
- С фибоначчиевой кучей: $O(|E| + |V| \log |V|)$.
- Для плотных графов ($|E| \approx |V|^2$) можно использовать простой массив без кучи: $O(|V|^2)$.

#### Пример
Граф: вершины A,B,C,D. Веса: A-B:2, A-C:3, B-C:1, B-D:4, C-D:5.  
Начало с A.  
- S={A}: key[B]=2, key[C]=3, key[D]=∞.  
- Извлекаем B (key=2). Добавляем ребро A-B. Обновляем: key[C] = min(3, 1) =1 через B; key[D] = min(∞,4)=4.  
- Извлекаем C (key=1). Добавляем B-C. Обновляем: key[D] = min(4,5)=4 (через B).  
- Извлекаем D (key=4). Добавляем B-D.  
MST: A-B, B-C, B-D, сумма=2+1+4=7.

### 22.3. Алгоритм Краскала

#### Идея
Алгоритм Краскала поддерживает **лес** (набор деревьев), изначально состоящий из изолированных вершин. Все рёбра сортируются по возрастанию веса. Рёбра рассматриваются по порядку; если ребро соединяет две разные компоненты связности текущего леса, оно добавляется в MST, а компоненты объединяются. Это соответствует безопасному ребру для леса: ребро минимального веса среди всех рёбер, соединяющих две различные компоненты, безопасно.

#### Псевдокод

```
Kruskal(G, w):
    отсортировать рёбра E по возрастанию веса w
    создать структуру Union-Find для вершин V (каждая вершина — отдельное множество)

    MST = пустой список

    для каждого ребра (u,v) из отсортированного списка:
        если find(u) ≠ find(v):        // вершины в разных компонентах
            MST.добавить((u,v))
            union(u, v)                // объединить компоненты

    вернуть MST
```

**Пояснения:**  
- Структура **Union-Find** (система непересекающихся множеств) поддерживает операции `find(x)` (возвращает идентификатор компоненты) и `union(x,y)` (объединяет компоненты).
- Сортировка рёбер даёт возможность всегда выбирать глобально минимальное ребро, ещё не создающее цикл.

#### Временная сложность
- Сортировка: $O(|E| \log |E|) = O(|E| \log |V|)$, так как $|E| \le |V|^2$.
- Обработка рёбер: $O(|E| \cdot \alpha(|V|))$, где $\alpha$ — обратная функция Аккермана, практически константа, при использовании эффективной Union-Find (с рангами и сжатием путей).
- Итого: $O(|E| \log |V|)$.

Алгоритм Краскала особенно эффективен для **разреженных** графов.

#### Пример
Тот же граф. Рёбра отсортированы: B-C (1), A-B (2), A-C (3), B-D (4), C-D (5).  
- B-C: разные компоненты → добавляем, объединяем {B,C}.
- A-B: разные ({A} и {B,C}) → добавляем, объединяем {A,B,C}.
- A-C: уже в одной компоненте (A и C) → пропускаем.
- B-D: разные → добавляем, объединяем {A,B,C,D}.
- MST готов, вес 7.

### 22.5. Применения минимальных остовных деревьев

- **Сетевой дизайн:** прокладка кабелей, трубопроводов, дорог с минимальной стоимостью, объединяющих все узлы.
- **Кластеризация:** построение MST и удаление самых длинных рёбер для разделения на кластеры.
- **Аппроксимация задачи коммивояжёра:** MST даёт нижнюю оценку; двойной обход MST даёт 2-приближение.
- **Анализ изображений:** сегментация на основе MST (алгоритм Фелзенштейна–Хюттенлохера).
- **Биоинформатика:** построение эволюционных деревьев.

---

### 22.6. Заключение

Алгоритмы Прима и Краскала — фундаментальные примеры жадных алгоритмов, решающих задачу MST за почти линейное время. Их элегантность, простота реализации и оптимальность делают их обязательными для изучения в любом курсе алгоритмов. Выбор между ними диктуется плотностью графа и конкретными особенностями задачи. Понимание этих алгоритмов также закладывает основу для более сложных конструкций, таких как алгоритм Борувки и его параллельные версии.
