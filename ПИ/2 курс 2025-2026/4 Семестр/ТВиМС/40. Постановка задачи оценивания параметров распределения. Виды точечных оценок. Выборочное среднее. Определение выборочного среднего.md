Ниже — подробный материал по теме **«Постановка задачи оценивания параметров распределения. Виды точечных оценок. Выборочное среднее»**. Тема открывает раздел математической статистики, посвящённый оцениванию неизвестных характеристик генеральной совокупности по выборке.

## 1. Постановка задачи оценивания параметров

### 1.1. Параметрическая модель
В математической статистике предполагается, что наблюдаемая случайная величина $X$ (признак генеральной совокупности) имеет распределение, принадлежащее некоторому **параметрическому семейству** $\mathcal{P} = \{ F(x; \theta),\; \theta \in \Theta \}$. Здесь $\theta$ — неизвестный параметр (скалярный или векторный), $\Theta$ — множество допустимых значений параметра.

**Примеры:**
- Нормальное распределение $\mathcal{N}(a, \sigma^2)$, параметры $a$ и $\sigma^2$ неизвестны.
- Распределение Пуассона $\mathrm{Pois}(\lambda)$ — неизвестен параметр $\lambda$.
- Биномиальное распределение $\mathrm{Bin}(n, p)$ при известном $n$ — неизвестна вероятность $p$.

### 1.2. Задача оценивания
Имеется **случайная выборка** $X_1, X_2, \dots, X_n$ — независимые случайные величины, каждая из которых распределена так же, как и генеральная совокупность $X$. По **реализации** выборки $x_1, x_2, \dots, x_n$ требуется построить приближённое значение неизвестного параметра $\theta$ (или функции от него). Это приближённое значение называют **оценкой** параметра.

Оценка $\hat{\theta}$ является **функцией выборки** (статистикой):
$$
\hat{\theta} = T(X_1, X_2, \dots, X_n).
$$
Подставляя конкретные наблюдения, получаем число — **реализованную оценку** $T(x_1, \dots, x_n)$.

Различают **точечное оценивание** (оценка — одно число) и **интервальное оценивание** (оценка — интервал, накрывающий параметр с заданной вероятностью). Здесь мы рассматриваем точечное оценивание.

## 2. Виды точечных оценок

Точечные оценки можно классифицировать по разным признакам: по тому, какой параметр оценивают, по методу построения, по статистическим свойствам.

### 2.1. По оцениваемому параметру
Наиболее распространённые параметры и их стандартные оценки:

| Параметр | Обозначение | Типичная оценка (статистика) |
|----------|-------------|-------------------------------|
| Математическое ожидание $\mu = E(X)$ | $\mu$ | **Выборочное среднее** $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ |
| Дисперсия $\sigma^2 = D(X)$ | $\sigma^2$ | **Выборочная дисперсия** $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$ (несмещённая) или $\frac{1}{n}\sum (X_i - \bar{X})^2$ (смещённая) |
| Вероятность успеха $p$ в схеме Бернулли | $p$ | **Выборочная доля** $\hat{p} = \frac{m}{n}$, где $m$ — число успехов |
| Параметр $\lambda$ распределения Пуассона | $\lambda$ | $\hat{\lambda} = \bar{X}$ |

Для разных распределений могут использоваться и другие оценки.

### 2.2. По методу построения
- **Метод моментов:** параметры выражаются через теоретические моменты, которые заменяются выборочными моментами. Например, для нормального распределения оценка $a$ — выборочное среднее, оценка $\sigma^2$ — выборочная дисперсия (смещённая).
- **Метод максимального правдоподобия:** оценка максимизирует функцию правдоподобия. Для многих распределений оценки совпадают с выборочным средним (нормальное, Пуассона, экспоненциальное и др.).

### 2.3. По статистическим свойствам
К оценкам предъявляют требования, чтобы они были «хорошими»:
- **Состоятельность:** $\hat{\theta}_n \xrightarrow{P} \theta$ при $n \to \infty$ (при большом объёме выборки оценка близка к истинному значению).
- **Несмещённость:** $E(\hat{\theta}) = \theta$ (отсутствие систематической ошибки).
- **Эффективность:** среди всех несмещённых оценок данная имеет минимальную дисперсию.
- **Асимптотическая нормальность** и др.

Эти свойства будут проиллюстрированы на примере выборочного среднего.

## 3. Выборочное среднее

### 3.1. Определение
Пусть $X_1, X_2, \dots, X_n$ — случайная выборка из генеральной совокупности с математическим ожиданием $\mu$ и дисперсией $\sigma^2$. **Выборочным средним** (или эмпирическим средним) называется статистика

$$
\boxed{ \bar{X} = \frac{1}{n} \sum_{i=1}^n X_i }.
$$

На реализации выборки $x_1, \dots, x_n$ её числовое значение равно среднему арифметическому наблюдений:
$$
\bar{x} = \frac{1}{n} \sum_{i=1}^n x_i.
$$

Выборочное среднее является естественной точечной оценкой математического ожидания $\mu$.

### 3.2. Пример вычисления
Вернёмся к данным о баллах 20 студентов (из тем 38, 39):  
55, 61, 72, 72, 85, 90, 55, 61, 78, 82, 88, 91, 72, 68, 68, 75, 81, 81, 95, 60.

Вычислим выборочное среднее:
$$
\bar{x} = \frac{55 + 61 + 72 + 72 + 85 + 90 + 55 + 61 + 78 + 82 + 88 + 91 + 72 + 68 + 68 + 75 + 81 + 81 + 95 + 60}{20}.
$$

Суммируем:  
$55+61=116$, $+72=188$, $+72=260$, $+85=345$, $+90=435$, $+55=490$, $+61=551$, $+78=629$, $+82=711$, $+88=799$, $+91=890$, $+72=962$, $+68=1030$, $+68=1098$, $+75=1173$, $+81=1254$, $+81=1335$, $+95=1430$, $+60=1490$.

Итак, сумма = 1490. Среднее:
$$
\bar{x} = \frac{1490}{20} = 74.5.
$$

Интерпретация: средний балл в выборке составляет 74.5. Это значение принимается за оценку среднего балла генеральной совокупности.

### 3.3. Свойства выборочного среднего

**1. Линейность и простота.**  
Выборочное среднее — простая линейная функция наблюдений, удобная для вычислений.

**2. Несмещённость.**  
Математическое ожидание выборочного среднего равно математическому ожиданию генеральной совокупности:
$$
E(\bar{X}) = \frac{1}{n} \sum_{i=1}^n E(X_i) = \frac{1}{n} \cdot n\mu = \mu.
$$
Таким образом, $\bar{X}$ — **несмещённая оценка** $\mu$: в среднем по всем возможным выборкам она даёт истинное значение параметра.

**3. Дисперсия и среднее квадратическое отклонение.**  
При независимости наблюдений:
$$
D(\bar{X}) = \frac{1}{n^2} \sum_{i=1}^n D(X_i) = \frac{n\sigma^2}{n^2} = \frac{\sigma^2}{n}, \qquad \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}.
$$
Дисперсия среднего убывает с ростом объёма выборки; точность оценки повышается.

**4. Состоятельность.**  
По закону больших чисел (слабый ЗБЧ, тема 35) $\bar{X}$ сходится по вероятности к $\mu$ при $n \to \infty$:
$$
\bar{X} \xrightarrow{P} \mu.
$$
Следовательно, $\bar{X}$ — **состоятельная оценка** $\mu$. С ростом $n$ она становится сколь угодно близкой к истинному значению.

**5. Распределение выборочного среднего.**  
Если генеральная совокупность распределена нормально $\mathcal{N}(\mu, \sigma^2)$, то $\bar{X} \sim \mathcal{N}\!\left(\mu, \frac{\sigma^2}{n}\right)$. Это позволяет строить доверительные интервалы и проверять гипотезы для $\mu$ при известной дисперсии.  
Если распределение генеральной совокупности не нормальное, но $n$ велико, то по центральной предельной теореме (тема 37)
$$
\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \xrightarrow{d} \mathcal{N}(0,1),
$$
т.е. $\bar{X}$ асимптотически нормально. Это свойство — основа многих методов статистического вывода.

**6. Эффективность.**  
В классе несмещённых линейных оценок $\mu$ выборочное среднее имеет наименьшую дисперсию (теорема Гаусса–Маркова для случая равных весов). Для нормального распределения $\bar{X}$ является **эффективной оценкой**: она достигает нижней границы дисперсии, предписываемой неравенством Рао–Крамера.

**7. Робастность.**  
Выборочное среднее чувствительно к выбросам (резко выделяющимся наблюдениям). В присутствии грубых ошибок его значение может сильно исказиться, что стимулирует использование альтернативных оценок центра (медианы, усечённого среднего) в таких ситуациях.

## 4. Резюме

- **Задача точечного оценивания** состоит в построении по выборке статистики, служащей приближением неизвестного параметра распределения.
- **Виды точечных оценок** различают по оцениваемому параметру (среднее, дисперсия, доля и др.), по методу построения (моментов, максимального правдоподобия) и по свойствам (состоятельные, несмещённые, эффективные).
- **Выборочное среднее** $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ — основная точечная оценка математического ожидания.
- **Свойства** $\bar{X}$: несмещённость ($E(\bar{X}) = \mu$), состоятельность ($\bar{X} \xrightarrow{P} \mu$), дисперсия $\sigma^2/n$, асимптотическая нормальность, а для нормальных данных — точное нормальное распределение. Это делает его центральным инструментом статистического анализа.
