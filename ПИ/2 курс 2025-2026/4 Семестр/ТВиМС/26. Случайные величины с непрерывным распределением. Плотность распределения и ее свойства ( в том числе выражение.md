Ниже — подробный материал о непрерывных случайных величинах, плотности распределения, её свойствах и геометрической интерпретации.

---

## 1. Непрерывная случайная величина

Случайная величина $X$ называется **непрерывной** (точнее, абсолютно непрерывной), если её функция распределения $F(x) = P(X < x)$ может быть представлена в виде интеграла от некоторой неотрицательной функции $f(t)$:

$$
F(x) = \int_{-\infty}^{x} f(t)\,dt, \qquad x \in \mathbb{R}.
$$

Функция $f(t)$ называется **плотностью распределения вероятностей** (или плотностью вероятности, дифференциальной функцией распределения) случайной величины $X$.

Из этого определения следует, что $F(x)$ непрерывна и почти всюду дифференцируема, причём $F'(x) = f(x)$ в точках непрерывности $f(x)$.

---

## 2. Плотность распределения и её связь с функцией распределения

Если случайная величина непрерывна, то её функция распределения восстанавливается по плотности интегрированием, а плотность — это производная функции распределения (там, где она существует):

$$
\boxed{f(x) = F'(x)} \quad \text{(почти всюду)}.
$$

Таким образом, плотность вероятности играет для непрерывной случайной величины ту же роль, что и ряд распределения для дискретной: она полностью описывает вероятностное поведение величины.

---

## 3. Свойства плотности распределения

### 3.1. Неотрицательность
$$
\boxed{f(x) \ge 0 \quad \text{для всех } x \in \mathbb{R}}.
$$
Это следует из того, что $F(x)$ не убывает, а значит, её производная (там, где существует) неотрицательна.

### 3.2. Условие нормировки
Интеграл от плотности по всей числовой прямой равен 1:
$$
\boxed{\int_{-\infty}^{\infty} f(x)\,dx = 1}.
$$
Действительно, $\int_{-\infty}^{\infty} f(x)\,dx = \lim_{x\to\infty} F(x) - \lim_{x\to-\infty} F(x) = 1 - 0 = 1$. Это аналог суммы вероятностей для дискретных величин.

### 3.3. Вероятность попадания в промежуток $[a, b)$
Вероятность того, что непрерывная случайная величина примет значение из полуинтервала $[a, b)$, равна интегралу от плотности по этому промежутку:

$$
\boxed{P(a \le X < b) = \int_{a}^{b} f(x)\,dx}.
$$

Это прямо следует из формулы $P(a \le X < b) = F(b) - F(a)$ и представления $F$ через интеграл.

Аналогично, вероятность попадания в любой интервал (открытый, замкнутый, полуоткрытый) равна интегралу от плотности по этому интервалу. Поскольку вероятность попадания в отдельную точку равна нулю (см. ниже), включение или исключение границ не меняет величину вероятности:
$$
P(a \le X \le b) = P(a < X < b) = \int_{a}^{b} f(x)\,dx.
$$

### 3.4. Выражение функции распределения через плотность
Как уже было сказано,
$$
F(x) = \int_{-\infty}^{x} f(t)\,dt.
$$
Геометрически $F(x)$ — это площадь под графиком плотности левее точки $x$.

### 3.5. Связь с элементарной вероятностью (локальный смысл плотности)
При малом $\Delta x > 0$
$$
P(x \le X < x + \Delta x) \approx f(x)\,\Delta x.
$$
Точнее, $f(x) = \lim_{\Delta x \to 0+} \frac{P(x \le X < x + \Delta x)}{\Delta x}$. Плотность показывает, насколько «плотно» вероятность сосредоточена в окрестности точки.

---

## 4. Геометрическая интерпретация

График плотности $y = f(x)$ — это неотрицательная кривая, вся площадь под которой равна 1.

- **Вероятность попадания в промежуток $[a, b)$** равна площади под графиком $f(x)$ над отрезком $[a, b]$.
- **Функция распределения $F(x)$** в точке $x$ равна площади под графиком плотности левее вертикальной прямой, проходящей через $x$.

Таким образом, задачи о вероятностях для непрерывных величин сводятся к вычислению площадей под кривой плотности.

---

## 5. Вероятность попадания в фиксированную точку

Для непрерывной случайной величины вероятность принять любое конкретное значение равна нулю:

$$
\boxed{P(X = a) = 0 \quad \text{для любого } a \in \mathbb{R}}.
$$

**Доказательство:**  
$P(X = a) = \lim_{\Delta x \to 0+} P(a \le X < a + \Delta x) = \lim_{\Delta x \to 0+} \int_{a}^{a+\Delta x} f(x)\,dx = 0$ в силу непрерывности интеграла по верхнему пределу (или просто потому, что интеграл по отрезку нулевой длины равен нулю). Более строго, $F(a+0) - F(a) = P(X \le a) - P(X < a) = P(X = a)$, но для абсолютно непрерывной величины $F$ непрерывна справа и слева, и скачков нет, значит, $P(X=a)=0$.

**Следствие:**  
- Возможные значения непрерывной случайной величины составляют целый интервал (или объединение интервалов), но вероятность каждого отдельного значения равна нулю.  
- События $\{X < a\}$ и $\{X \le a\}$ имеют одинаковую вероятность.  
- При вычислении вероятностей интервалов можно не различать строгие и нестрогие неравенства.

## 6. Пример: равномерное распределение на отрезке $[0, 1]$

Говорят, что случайная величина $X$ равномерно распределена на отрезке $[0, 1]$, если её плотность постоянна на этом отрезке и равна нулю вне его:

$$
f(x) = \begin{cases}
1, & 0 \le x \le 1, \\
0, & \text{иначе}.
\end{cases}
$$

**Проверим свойства:**
- $f(x) \ge 0$.
- $\int_{-\infty}^{\infty} f(x)\,dx = \int_{0}^{1} 1\,dx = 1$ — условие нормировки выполнено.

**Функция распределения:**  
Для $x < 0$: $F(x) = 0$.  
Для $0 \le x \le 1$: $F(x) = \int_{0}^{x} 1\,dt = x$.  
Для $x > 1$: $F(x) = 1$.

**Вероятность попадания в интервал:** например, $P(0.2 \le X < 0.6) = \int_{0.2}^{0.6} 1\,dx = 0.4$. Геометрически это площадь прямоугольника с основанием $0.4$ и высотой $1$.

**Вероятность попадания в точку:** $P(X = 0.5) = 0$.

Такой пример наглядно демонстрирует все свойства непрерывного распределения и плотности.

---

## 7. Резюме

| Понятие | Определение / Формула |
|---------|----------------------|
| **Непрерывная СВ** | СВ с абсолютно непрерывной функцией распределения |
| **Плотность распределения** $f(x)$ | $f(x) = F'(x)$ почти всюду; $f(x) \ge 0$ |
| **Условие нормировки** | $\int_{-\infty}^{\infty} f(x)\,dx = 1$ |
| **Вероятность попадания в $[a,b)$** | $P(a \le X < b) = \int_{a}^{b} f(x)\,dx$ |
| **Функция распределения** | $F(x) = \int_{-\infty}^{x} f(t)\,dt$ |
| **Геометрический смысл** | Вероятность = площадь под кривой плотности |
| **Вероятность в точке** | $P(X = a) = 0$ |

Плотность распределения — основной инструмент для работы с непрерывными случайными величинами, позволяющий сводить вероятностные задачи к вычислению интегралов и наглядно представлять распределение графически.
