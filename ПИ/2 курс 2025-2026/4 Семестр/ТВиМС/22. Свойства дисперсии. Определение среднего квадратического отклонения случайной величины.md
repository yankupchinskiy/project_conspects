Ниже — подробный материал по теме «Свойства дисперсии. Среднее квадратическое отклонение». Он опирается на определение дисперсии из предыдущей темы и систематизирует её ключевые свойства, а также вводит понятие среднего квадратического отклонения.

---

## 1. Дисперсия (повторение определения)

**Дисперсией** случайной величины \(X\) называется математическое ожидание квадрата её отклонения от математического ожидания:

\[
D(X) = \mathrm{Var}(X) = M\Bigl[\bigl(X - M(X)\bigr)^2\Bigr].
\]

Для дискретной случайной величины с рядом распределения \(P(X = x_i) = p_i\) это записывается как:

\[
D(X) = \sum_i \bigl(x_i - M(X)\bigr)^2 p_i.
\]

Основная **вычислительная формула**:

\[
\boxed{D(X) = M(X^2) - [M(X)]^2}.
\]

Дисперсия всегда неотрицательна. Далее мы подробно рассмотрим её свойства.

---

## 2. Свойства дисперсии

### 2.1. Дисперсия константы
Для любой постоянной \(c\):

\[
\boxed{D(c) = 0.}
\]

Константа не имеет разброса — её значение фиксировано. Формально: \(M(c) = c\), тогда \(D(c) = M[(c - c)^2] = M(0) = 0\).

### 2.2. Неотрицательность и условие нулевой дисперсии
\[
D(X) \ge 0.
\]
Причём \(D(X) = 0\) тогда и только тогда, когда случайная величина почти наверное постоянна (принимает одно значение с вероятностью 1). Если \(D(X) > 0\), говорят, что величина обладает разбросом.

### 2.3. Влияние линейного преобразования

#### а) Прибавление константы
\[
\boxed{D(X + c) = D(X).}
\]
Сдвиг на постоянную не меняет разброс: отклонения от среднего не изменяются, потому что \(M(X + c) = M(X) + c\), и \((X + c - (M(X) + c)) = X - M(X)\).

**Пример:** Дисперсия температуры в градусах Цельсия и Кельвина одинакова.

#### б) Умножение на константу
\[
\boxed{D(cX) = c^2 D(X).}
\]
Постоянный множитель выносится с квадратом: при умножении величины на \(c\) её отклонения от среднего умножаются на \(c\), а квадраты отклонений — на \(c^2\).

**Пример:** Если доход увеличивается в 10 раз, его дисперсия возрастает в 100 раз.

### 2.4. Дисперсия суммы (общий случай)
Для любых двух случайных величин \(X\) и \(Y\) с конечными дисперсиями:

\[
\boxed{D(X + Y) = D(X) + D(Y) + 2\,\mathrm{cov}(X,Y)},
\]

где **ковариация** \(\mathrm{cov}(X,Y) = M\Bigl[\bigl(X - M(X)\bigr)\bigl(Y - M(Y)\bigr)\Bigr] = M(XY) - M(X)M(Y)\).

Если \(X\) и \(Y\) **независимы**, то \(\mathrm{cov}(X,Y) = 0\), и формула упрощается:

\[
\boxed{D(X + Y) = D(X) + D(Y) \quad \text{(при независимости)}.}
\]

Аналогично для разности:

\[
D(X - Y) = D(X) + D(Y) - 2\,\mathrm{cov}(X,Y),
\]

а в случае независимости:

\[
D(X - Y) = D(X) + D(Y) \quad \text{(при независимости)}.
\]

**Интуиция:** Для независимых величин дисперсии суммируются, разброс накапливается.

### 2.5. Обобщение на сумму нескольких случайных величин
Если \(X_1, X_2, \dots, X_n\) **попарно независимы**, то дисперсия их суммы равна сумме дисперсий:

\[
\boxed{D\!\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n D(X_i)}.
\]

Для линейной комбинации независимых величин с постоянными коэффициентами:

\[
\boxed{D\!\left(\sum_{i=1}^n a_i X_i\right) = \sum_{i=1}^n a_i^2 D(X_i)}.
\]

**Пример (испытания Бернулли):** Пусть \(X_i\) — индикатор успеха в \(i\)-м испытании (1 с вероятностью \(p\), 0 с вероятностью \(q\)). Тогда \(D(X_i) = p q\). Для общего числа успехов \(S_n = \sum_{i=1}^n X_i\) (независимые) дисперсия \(D(S_n) = n p q\).

### 2.6. Связь с математическим ожиданием (вычислительная формула)
Уже упомянутое, но важное свойство:

\[
\boxed{D(X) = M(X^2) - [M(X)]^2.}
\]

Это тождество часто используют для расчёта дисперсии на практике.

### 2.7. Дисперсия произведения (только при независимости)
Если \(X\) и \(Y\) независимы, то

\[
D(XY) = M(X^2)M(Y^2) - [M(X)]^2 [M(Y)]^2.
\]

Выводится из \(D(XY) = M(X^2 Y^2) - [M(XY)]^2\) и свойств независимости.

## 3. Среднее квадратическое отклонение

### 3.1. Определение
Дисперсия имеет размерность квадрата размерности исходной случайной величины, что не всегда удобно. Чтобы получить характеристику разброса в тех же единицах, что и сама величина, вводят **среднее квадратическое отклонение** (стандартное отклонение, СКО) \(\sigma\):

\[
\boxed{\sigma(X) = \sqrt{D(X)}.}
\]

Обозначения: \(\sigma_X\), \(\sigma\), \(s_X\). Всегда \(\sigma(X) \ge 0\).

**Интерпретация:** Среднее квадратическое отклонение показывает, насколько в среднем значения случайной величины отклоняются от её математического ожидания.

### 3.2. Свойства среднего квадратического отклонения
Прямо следуют из свойств дисперсии:

1. **Сдвиг:** \(\sigma(X + c) = \sigma(X)\) (прибавление константы не меняет разброс).

2. **Масштабирование:** \(\sigma(cX) = |c| \,\sigma(X)\).  
   Модуль появляется, потому что корень из \(c^2\) даёт \(|c|\).

3. **Сумма независимых величин:** если \(X\) и \(Y\) независимы, то
   \[
   \sigma(X + Y) = \sqrt{\sigma^2(X) + \sigma^2(Y)}.
   \]
   Это прямо следует из \(D(X+Y) = D(X) + D(Y)\) при независимости.

4. Для любого \(c\) правило трёх сигм (неравенство Чебышёва): доля значений, лежащих вне интервала \(M \pm k\sigma\), не превышает \(1/k^2\). В частности, для многих распределений почти все значения (около 99,7% для нормального) лежат в пределах \(M \pm 3\sigma\).

## 4. Пример (две игральные кости)

Вернёмся к примеру из темы 21. Случайная величина \(X\) — сумма очков при бросании двух правильных костей.

Ряд распределения уже известен, математическое ожидание \(M(X) = 7\).

Ранее мы вычислили:
\[
M(X^2) = \frac{1974}{36} = \frac{329}{6} \approx 54{,}8333.
\]

Дисперсия:
\[
D(X) = M(X^2) - [M(X)]^2 = \frac{1974}{36} - 49 = \frac{210}{36} = \frac{35}{6} \approx 5{,}8333.
\]

**Среднее квадратическое отклонение:**
\[
\sigma(X) = \sqrt{\frac{35}{6}} \approx \sqrt{5{,}8333} \approx 2{,}415.
\]

Интерпретация: при многократных бросаниях двух костей сумма очков в среднем будет колебаться около 7, причём типичные отклонения составляют примерно 2,4. Большинство результатов (по правилу трёх сигм, точнее по неравенству Чебышёва, но здесь распределение симметричное и колоколообразное) будут в диапазоне от \(7 - 2\cdot 2{,}415 \approx 2{,}2\) до \(11{,}8\), что почти полный диапазон 2–12.

## 5. Резюме

| Свойство | Формула | Примечание |
|----------|---------|------------|
| Дисперсия константы | \(D(c)=0\) | |
| Сдвиг | \(D(X+c)=D(X)\) | |
| Масштаб | \(D(cX)=c^2 D(X)\) | |
| Сумма (общий случай) | \(D(X+Y)=D(X)+D(Y)+2\mathrm{cov}(X,Y)\) | |
| Сумма независимых | \(D(X+Y)=D(X)+D(Y)\) | попарная независимость |
| Линейная комбинация независимых | \(D(\sum a_i X_i)=\sum a_i^2 D(X_i)\) | |
| Вычислительная формула | \(D(X)=M(X^2)-[M(X)]^2\) | |
| Среднее квадратическое отклонение | \(\sigma(X)=\sqrt{D(X)}\) | мера разброса в исходных единицах |
| Свойства СКО | \(\sigma(cX)=\|c\|\sigma(X)\), \(\sigma(X+c)=\sigma(X)\) | |

Дисперсия и среднее квадратическое отклонение — основные меры рассеяния случайной величины. Они позволяют количественно оценить неопределённость и вариацию, играя ключевую роль в статистических выводах, финансовом анализе, контроле качества и многих других областях.
